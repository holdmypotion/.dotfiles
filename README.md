# Dotfiles

My personal dotfiles.

## Installation

```bash
git clone --recurse-submodules https://github.com/holdmypotion/.dotfiles.git ~/.dotfiles
```

## Structure

* `.zshrc`: Zsh configuration
* `.tmux.conf`: Tmux configuration
* `.config/`: Application configurations
